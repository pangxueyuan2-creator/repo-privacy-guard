# Roadmap

## Near term

- Add a documented baseline file for accepted historical findings.
- Improve Git-aware scanning of commit ranges (staged-file scanning is done via `--staged`).
- Add more provider patterns backed by synthetic fixtures.
- Add optional GitHub code-scanning upload documentation for SARIF reports.

## Later

- Publish signed npm releases after package ownership is configured.
- Add a small offline web interface for non-technical users.
- Provide localized CLI output.
- Benchmark detection quality against a public synthetic corpus.

Roadmap items are proposals, not promises. Open an issue before substantial work.
